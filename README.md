# MatRisk-AI

AI-powered Infrastructure Risk Assessment System

## Overview
MatRisk-AI predicts infrastructure condition and failure risks using engineered features and machine learning.

## Datasets
- DS1: Material Properties
- DS2: Commodity Prices
- DS3: Infrastructure Bridges
- DS4: Cross-Domain Risk Factors
- DS5: Element Prices
- DS6: Historical Failures

## Feature Engineering
Examples:
- Corrosion Exposure Score
- Traffic Stress Score
- Remaining Life Ratio
- Severity Loss Score
- Failure Risk Score

## Machine Learning Models

### DS3 Bridge Condition Prediction
Target: condition_rating
Algorithm: Random Forest Regressor

### DS6 Failure Risk Prediction
Target: failure_risk_score
Algorithm: Random Forest Regressor
